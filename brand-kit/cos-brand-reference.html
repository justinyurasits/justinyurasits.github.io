Build rules — what the system enforces
Palette
  • Seven tokens only — no grays, blues, or purples outside this set
  • Revision #C43230 marks a measured delta only — never accent, never background
  • Graphite / Line gray swap by surface (see pairing table above)
  • Line gray text on Bond = 1.7:1 — never do this
Typography
  • Archivo only — no second typeface
  • 600 headings · 500 labels/eyebrows · 400 body
  • Sentence case everywhere, including the wordmark
  • Never set "OS" apart in caps, another color, or a block
Layout & geometry
  • No gradients, rounded containers, drop shadows, or icon tiles
  • Linework only — fill="none", stroke geometry, 1–2px rules
  • Rules span containers, not grid cells — a section divider goes on the wrapper
  • In auto-fit grids, every cell carries identical padding and borders
Icons
  • Keep viewBox="0 0 100 100" — altering it clips the geometry
  • Stroke widths (4–12) are calibrated to the 100-unit box — do not override
  • On Ink surfaces: Paper strokes, Line gray accent
  • On Paper/Bond: Ink strokes, Steel accent
